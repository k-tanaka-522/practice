# 01-基礎インフラストラクチャー編

## 🚨 重要な注意事項

**⚠️ このモジュールは学習目的で簡素化されています**

本モジュールでは学習効率を重視し、**Administrator権限**での簡単なセットアップ手順を提供しています。

### 📋 本番環境での注意点

```yaml
🚫 本番環境では使用しないでください:
  - Administrator権限の常用
  - 過度に緩いセキュリティ設定
  - 最小権限原則の無視

✅ 本来のあるべき姿:
  - IAMロールベースの詳細な権限管理
  - 最小権限原則の徹底
  - セキュリティグループの厳密な設定
  - 監査ログの有効化
  - MFA(多要素認証)の必須化
```

## 🎯 学習目標

Administrator権限を使用して、AWSの基礎的なインフラストラクチャサービスを**迅速に**学習し、クラウド環境の基本概念を理解することを目指します。

### 主要な学習成果
- **VPCネットワーク設計**: セキュアなプライベートネットワークの基本概念
- **EC2とコンピューティング**: 仮想マシンの基本操作
- **ロードバランサー**: 高可用性の基本アーキテクチャ
- **RDSデータベース**: 管理型データベースの基本活用

## 🚀 簡単セットアップ

### 前提条件

```bash
# AWS CLI設定（Administrator権限）
aws configure
# Access Key ID: [Administrator権限のアクセスキー]
# Secret Access Key: [対応するシークレットキー]
# Default region: ap-northeast-1
# Default output format: json

# 設定確認
aws sts get-caller-identity
```

### ワンクリックデプロイ

```bash
# 全セクション一括デプロイ（学習用）
cd 01-基礎インフラストラクチャー編
./scripts/quick-deploy-all.sh

# または段階的デプロイ
./scripts/quick-deploy.sh vpc
./scripts/quick-deploy.sh ec2
./scripts/quick-deploy.sh rds
```
