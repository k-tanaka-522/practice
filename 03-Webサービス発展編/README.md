# 03-Webサービス発展編

SNS風Webアプリケーションの完全実装を通じて、実用的なWebサービス開発を学習します。

## 学習目標

- フルスタックWebアプリケーションの開発
- CRUD操作の完全実装
- ファイルアップロードとメディア処理
- リレーショナルデータベースの活用
- リアルタイム機能の実装
- 実運用レベルのWebサービス構築

## 前提条件

- 02-Webアプリケーション基礎編の完了
- JavaScript/Node.js の基礎知識
- HTML/CSS の基礎知識
- AWS基本サービスの理解

## 最終成果物

SNS風Webアプリケーション
- ユーザー投稿機能
- 画像アップロード機能
- リアルタイム通知
- フォロー/フォロワー機能
- レスポンシブデザイン

## 学習コンテンツ構成

### 0.0-前提条件確認 (30分)
モジュール02の成果物確認と環境準備

**学習内容:**
- 前モジュール完了確認
- 開発環境セットアップ
- 必要ライブラリのインストール

### 3.1-CRUD機能実装 (2時間)
投稿システムの基本CRUD操作実装

**学習内容:**
- REST API設計
- 投稿作成・読取・更新・削除
- バリデーション実装
- エラーハンドリング

**実装項目:**
- Express.js APIサーバー
- DynamoDB操作
- フロントエンド連携

### 3.2-ファイルアップロード (2時間)
S3を活用した画像アップロード機能

**学習内容:**
- マルチパートファイルアップロード
- S3バケット設定
- 画像リサイズ処理
- CDN配信設定

**実装項目:**
- ファイルアップロードAPI
- 画像処理Lambda
- CloudFront配信

### 3.3-データベース発展 (2時間)
PostgreSQLを使った関係データベース設計

**学習内容:**
- RDS PostgreSQL構築
- ER図設計
- リレーショナルクエリ
- データマイグレーション

**実装項目:**
- ユーザー管理テーブル
- 投稿テーブル
- フォロー関係テーブル
- いいね機能テーブル

### 3.4-リアルタイム機能 (2時間)
WebSocket APIを使ったリアルタイム通信

**学習内容:**
- API Gateway WebSocket
- リアルタイム通知
- 接続管理
- メッセージ配信

**実装項目:**
- WebSocket接続処理
- 通知配信システム
- オンライン状態管理

### 3.5-本格的なWebアプリ (2時間)
全機能統合とUI/UX改善

**学習内容:**
- 機能統合
- UI/UXブラッシュアップ
- パフォーマンス最適化
- セキュリティ強化

**実装項目:**
- 統合フロントエンド
- レスポンシブデザイン
- PWA対応
