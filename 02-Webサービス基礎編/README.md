# 02-Webサービス基礎編

## 🎯 このモジュールで学ぶこと

**基本的なWebアプリケーションの仕組みを理解し、AWS上でシンプルなWebサービスを構築**します。静的サイトから始まり、API、認証、データベースまで、Web開発の基礎を段階的に習得します。

### 学習目標

1. **Web三層アーキテクチャの理解**: フロントエンド、API、データベースの関係性
2. **AWS基本サービスの操作**: S3、CloudFront、API Gateway、Lambda、Cognito、DynamoDB
3. **認証の仕組み理解**: JWTトークン、セッション管理の基礎
4. **API設計基礎**: RESTful API、エラーハンドリング、セキュリティ

## 📚 学習パス

### **学習時間**: 約12時間
### **前提条件**: 01-基礎インフラストラクチャー編の完了

```
0.0 前提条件確認      [30分] → 01編の環境確認
2.1 静的サイト構築    [2時間] → S3 + CloudFront
2.2 API基盤構築      [3時間] → API Gateway + Lambda
2.3 認証システム      [3時間] → Cognito + JWT
2.4 データベース基礎   [2時間] → DynamoDB + 基本操作
2.5 簡単なWebアプリ   [1.5時間] → React + 統合
```

## 🎯 最終成果物

### **シンプルなWebアプリケーション**

**機能**:
- ユーザー登録・ログイン
- 簡単なプロフィール表示
- 基本的なAPI呼び出し
- レスポンシブデザイン

**技術スタック**:
- **フロントエンド**: React SPA (S3 + CloudFront)
- **API**: API Gateway + Lambda
- **認証**: Cognito User Pool
- **データベース**: DynamoDB
- **インフラ**: CloudFormation
